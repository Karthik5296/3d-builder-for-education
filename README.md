# 3D Builder for Education

A lightweight educational 3D builder prototype for creating simple scenes, exploring geometry, and learning design concepts.

## Features

- Build simple 3D scenes from geometric shapes
- Switch between cube, sphere, cone, and cylinder parts
- Adjust size and color
- Orbit and inspect models in 3D
- Lesson panel with guided educational prompts

## Getting started

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.

## Build for production

```bash
npm run build
```

## Tech stack

- React
- Vite
- Three.js
- @react-three/fiber
- @react-three/drei
